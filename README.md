# a11y-user-flows

> **Internal use only.** This repository exists solely to host a Payload CMS instance for accessibility audit and user flow testing. It is not intended for public consumption, production use, or external contribution.

## Purpose

This project is a Payload CMS app used to test and audit accessibility across Payload admin UI user flows. It covers a range of field types, collection configurations, and interaction patterns needed to evaluate screen reader compatibility, keyboard navigation, and WCAG compliance.

## Not for general use

- This is not a template or starter project
- No support is provided
- The content and configuration may change without notice
